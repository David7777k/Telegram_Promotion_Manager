# Telegram Promotion Studio 3.0

Windows приложение для согласованных публикаций в Telegram. Данные, черновики и история хранятся локально.

## Запуск

Откройте TelegramPromotionStudio.exe в корне проекта или распакуйте весь release/TelegramPromotionStudio-Windows-x64.zip и запустите EXE из распакованной папки. Папка _internal должна лежать рядом. Профиль по умолчанию находится в %LOCALAPPDATA%\TelegramPromotionStudio.

Запуск из исходников, Windows и Python 3.12+:

~~~powershell
python -m pip install -e ".[desktop]"
python -m promotion_studio --desktop --profile "$env:LOCALAPPDATA\TelegramPromotionStudio"
~~~

Для проверок подставьте отдельный путь к профилю. Старый Tkinter доступен отдельной командой python app.py.

## Рабочий сценарий

1. В разделе «Аккаунты» добавьте личный аккаунт или бота. Для личного аккаунта нужны API ID и API Hash из my.telegram.org. Вход поддерживает QR в Telegram или номер телефона, код и пароль двухэтапной проверки. Для бота нужен токен от @BotFather. Сессии зашифрованы Windows DPAPI.
2. В разделе «Площадки» синхронизируйте диалоги личного аккаунта или добавьте площадки вручную. Для публичного поиска Telegram возвращает ограниченную выдачу. Импорт поддерживает текст и TXT с одной ссылкой или ID на строку, а также CSV с колонкой chat_id, link или username. Колонки name и category необязательны.
3. У выбранных площадок откройте «Условия» и укажите рекламный статус. Технические права отправителя проверяются отдельно. Наличие группы в результатах поиска или синхронизации не выдаёт согласие на размещение.
4. В разделе «Кампании» введите текст, при необходимости укажите ссылку, фото или платное предложение. Добавьте площадки. Для каждой назначьте отправителя, время, срок согласия, интервал и допустимое число публикаций. Проверка показывает проблемы до утверждения. Studio атомарно создаёт задания с зафиксированным содержимым.
5. Ручные задания отправляются из очереди после подтверждения. Для автоматических отметьте разрешение в редакторе и отдельно включите расписание в боковом меню. Выполнение работает, пока открыто приложение. После перезапуска расписание выключено.
6. При состоянии «Нужна сверка» откройте площадку в Telegram и проверьте, появился ли пост. В Studio укажите ID подтверждённого сообщения и время либо закройте запись после сверки. Неопределённое задание не повторяется автоматически.

Личный аккаунт публикует текст и фото со ссылкой в тексте. Для подключённого бота можно выбрать кнопку. Платное предложение использует готовую ссылку Telegram Stars. В разделе «Шаблоны» доступны сохранение версий, сравнение до десяти вариантов и предварительная подстановка переменных.

«Стоп отправки» выключает расписание, ставит ожидающие автоматические задания на паузу и прекращает текущую попытку, если сетевой запрос отправки ещё не начался. Если запрос уже ушёл, результат будет записан в очередь.

Раздел «Аналитика» показывает данные очереди, известные расходы и реальные попытки. Покупки, клики и просмотры не подставляются как статистика. Выбор другого отправителя всегда требует решения оператора.

## Проверка и сборка

~~~powershell
python -m pip install -e ".[desktop]" pyinstaller
python -m unittest discover -v
.\packaging\build_windows.ps1 -Python python
python packaging/verify_windows.py release/TelegramPromotionStudio-Windows-x64.zip tests/fixtures/v2.json
~~~

Тесты выполняются на временных профилях с имитацией Telegram. Для проверки реальной отправки нужен отдельно разрешённый тестовый чат.

## Данные и перенос

Миграции выполняются при открытии профиля. «Настройки» создают копию локальной базы без токенов и сессий и позволяют восстановить её в новый профиль. Для открытия восстановленного профиля передайте EXE параметры --desktop --profile и путь к папке. DPAPI привязывает зашифрованные данные к текущему пользователю Windows. После восстановления потребуется заново подключить отправителей. Старые JSON данные можно переносить через команды --stage-legacy и --import-archive. Используйте --help для всех опций.

Текущие ограничения и результаты проверок перечислены в PROJECT_STATUS.md.
